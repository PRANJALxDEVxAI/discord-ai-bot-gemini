# Discord AI Bot (Gemini)

An AI-powered Discord bot developed in Python that integrates Google's Gemini API to generate intelligent, real-time responses for Discord communities.

## Features

- AI-powered conversations
- Real-time response generation
- Discord command support
- Google Gemini API integration
- Secure API key management using environment variables
- Error handling

## Technologies Used

- Python 3
- discord.py
- google-genai
- python-dotenv

## Installation

```bash
git clone https://github.com/PRANJALxDEVxAI/discord-ai-bot-gemini.git
cd discord-ai-bot-gemini
```

## Usage

```bash
python main.py
```
